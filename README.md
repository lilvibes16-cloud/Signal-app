# SIGNAL

A demo-first creator opportunity discovery SaaS MVP.

## Development

Node.js 20+ required.

```bash
npm install
npm run dev
npm test
npm run build
```

## Deployment

Deploy as a static Vite site: build command `npm run build`, output directory `dist`. No secrets or paid services needed.

## Data and privacy

All topics and figures are **DEMO DATA**, not live YouTube analytics or predictive accuracy claims. Watchlist entries are stored in this browser using localStorage, with no cross-device sync. Future live integration should use authenticated YouTube APIs and secure server-side credentials.
